# 羽島サーキュラーエコノミープロジェクト｜画像差し替えの引き継ぎ

このファイルの使い方は2段階です。

- **A** を ChatGPT（Image 2.5）に貼って画像を5枚つくる
- **B** を Claude Code に貼って、サイトの画像を差し替えて公開する

---

## A. ChatGPT（Image 2.5）に貼るプロンプト

```
岐阜県羽島市のWebサイト「羽島サーキュラーエコノミープロジェクト」で使う写真風の画像を5枚つくってください。
このプロジェクトでは、紡績会社（長谷虎紡績）の工場の近くを流れる小さな川「桑原川」で、生きものや水を調べ、地域の人と一緒に学びます。

■ 5枚に共通するトーン
- 実写のドキュメンタリー写真のような質感。35mmレンズ・自然光・やや低めのコントラスト・少し彩度を抑える
- 舞台は濃尾平野の田園地帯：平らな土地、田んぼ、用水路のような幅5〜10mの小さな川、遠くに低い山並み、ところどころに民家や工場の屋根
- 色の基調は、藍色 #205377、若い稲の緑 #84A94C、淡い水色 #E4EEF0、白。派手なシアンやトロピカルな青、夕焼けのオレンジは使わない
- 季節は初夏（5〜6月）。晴れか薄曇り
- 文字・看板・ロゴ・透かしは一切入れない
- 人物を入れるときは後ろ姿か遠景にして、顔が判別できないようにする
- CG、イラスト、HDRっぽい過剰な仕上げにはしない

■ 1枚目：hero.jpg（トップの全面写真）
- 横長 16:9（2400×1350px 以上）
- 田植えが終わったばかりの水田と、そのあいだを流れる小さな川。手前に川と土手の草、奥に田んぼと遠くの低い山、空は広め
- 画面の左下3分の1に白い文字が乗るので、左下は暗すぎず、細かい模様が少ない落ち着いた面（水面・稲・土手など）にする
- スマホでは中央が縦長に切り抜かれるので、主役（川の流れ）は中央付近に置く

■ 2枚目：river-life.jpg（トップ「工場の排水と、川の生きもの」）
- 横長 16:9（1800×1000px 以上）。左右の端が楕円に切り抜かれるので、主役は中央に
- 澄んだ浅い川の水中を、真横から見た写真。小さな淡水魚（オイカワやモツゴのような銀色の小魚）が数匹、川底の小石と水草
- 明るく清潔な印象。濁りやゴミは入れない

■ 3枚目：plain.jpg（プロジェクト紹介・説明会イベント）
- 横長 16:9（1800×1000px 以上）。左右の端が楕円に切り抜かれる
- 少し高い位置から見下ろした田園風景。手前に田んぼと小さな川、中ほどに民家と低い工場の建物（紡績工場をイメージした、のこぎり屋根か平屋の大きな建物）、奥に低い山
- 工場と田んぼと川が同じ風景の中で共存している感じ

■ 4枚目：kids-river.jpg（親子向けイベント・「一緒に調べてみませんか」欄）
- 横長 3:2（1800×1200px 以上）
- 小さな川の浅瀬で、親子2〜3組がタモ網とバケツで生きものを探している。全員うしろ姿か横向きで、顔はわからない。長靴、帽子
- 楽しそうな雰囲気だが、演出しすぎない自然なスナップ

■ 5枚目：workshop.jpg（企業・学校向けの説明会イベント）
- 横長 3:2（1800×1200px 以上）
- 地域の公民館のような明るい部屋。長机の上に小さな水槽（川の水と小魚、水草）が置かれ、大人4〜6人がそれを囲んで話している。人物はうしろ姿か手元だけ
- 机の上に地図や資料も少し。白い壁、窓からの自然光

5枚とも同じ地域・同じ季節に撮った写真に見えるよう、色味と光をそろえてください。
```

## B. Claude Code に貼るプロンプト

画像を `~/Sites/hashima-circular/_incoming/` に入れてから、`~/Sites/hashima-circular` で Claude Code を起動して貼ってください。

```
_incoming/ に ChatGPT で生成した画像を5枚置いた（hero.jpg / river-life.jpg / plain.jpg / kids-river.jpg / workshop.jpg）。
CLAUDE.md と DESIGN.md を読んでから、サイトの写真を差し替えて公開して。

1. まず git pull し、未 push のコミットがあれば先に push する
2. 画像を縮小して public/images/ に保存する
   - hero.jpg → 長辺2000px、それ以外 → 長辺1600px
   - JPEG 品質80・プログレッシブ。EXIF などのメタデータは消す
3. 差し替える場所（既存の画像ファイルは参照がなくなったら削除）
   - src/pages/index.astro のヒーロー: images/hero-paddy.jpg → images/hero.jpg
   - src/pages/index.astro の About の楕円写真: images/lab-fish.jpg → images/river-life.jpg
   - src/pages/about.astro の楕円写真: images/fields-town.jpg → images/plain.jpg
   - src/components/JoinCTA.astro の楕円写真: images/boy-river.jpg → images/kids-river.jpg
   - src/content/events/kuwabara-ikimono.md の cover: images/kids-river.jpg
   - src/content/events/partner-session.md の cover: images/workshop.jpg
   - 活動報告（src/content/news/*.md）の cover は、実際の水槽実験の写真（lab-tanks.jpg / lab-setup.jpg）のまま変えない
4. 生成画像のクレジットは全部「イメージ（AI生成）」にする（Photo の credit、記事・イベントの coverCredit）。実際の桑原川や羽島の写真だと誤解される書き方はしない
5. alt は画像の中身に合わせて日本語で書き直す
6. npm run build が通ること、PCとスマホ幅で見た目が崩れていないこと（ヒーローの文字が読めるか、楕円の中で主役が切れていないか）を確認する。切れていたら object-position で調整する
7. _incoming/ は .gitignore 済み。コミットしない
8. コミットして push する。公開後に https://hashima-circular.innoqua.jp/ で反映を確認する
```

## メモ

- **差し替えない画像：** 活動報告の写真は、Driveの「長谷虎プロジェクト/BETA」にある実際の水槽実験の写真です。報告記事なので本物のままにしています
- **OGP画像：** SNS共有用の `public/og.png` は文字だけの画像なので、差し替えは不要です
- **未pushのコミット：** Macにはまだpushしていないコミット（Unsplashの写真を入れた版と、このメモ）があります。B の手順1で先にpushされます
